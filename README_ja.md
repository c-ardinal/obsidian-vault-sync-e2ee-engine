# Vault-Sync E2EE Engine

[ [🇺🇸 English](README.md) | [🇯🇵 日本語](README_ja.md) ]

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

[Vault-Sync](https://github.com/c-ardinal/obsidian-vault-sync) 専用の外部E2EEエンジンです。  
Vault-Sync がアップロードする全 Vault データを暗号化し、ダウンロード時にローカル上で復号します。  
クラウド側で平文を参照する手段はありません。

---

## ✨ 機能

- **AES-256-GCM 暗号化**:
    - 業界標準の認証付き暗号化で全 Vault ファイルを保護
- **PBKDF2 鍵導出**:
    - パスワードから 600,000 回のイテレーションでマスターキーを導出
- **ファイル単位のランダム IV**:
    - 暗号化処理単位で一意の初期化ベクトルを使用し、暗号文のパターン分析を防止
- **パスワード強度チェッカー**:
    - セットアップ時に強度インジケータを表示（zxcvbn ベースのスコアリング）
- **自動ロック解除**:
    - Obsidianのセキュアストレージ（Keychain）にパスワードを保存し、起動時の入力を省略可能
- **透過的な統合**:
    - Vault-Sync のスマート同期（3-way マージ、競合検出、履歴表示）が暗号化データでもシームレスに動作
- **ワンクリック移行**:
    - セットアップウィザードが既存 Vault データの暗号化と整合性検証を自動処理

## ⌨️ コマンド（コマンドパレットから実行）

E2EE Engine のインストール後、Obsidian のコマンドパレットで以下のコマンドが利用可能になります:

| コマンド                                | 説明                                         |
| --------------------------------------- | -------------------------------------------- |
| E2EE: Vaultの暗号化を開始する           | 非暗号化 Vault で E2EE を初期化              |
| E2EE: Vaultのロックを解除する           | ロック中の Vault をパスワードで解除          |
| E2EE: 暗号化パスワードを変更する        | マスターキーを新パスワードで再ラッピング     |
| E2EE: リカバリーコードを表示する        | リカバリーコードと鍵フィンガープリントを表示 |
| E2EE: リカバリーコードでVaultを復元する | リカバリーコードで Vault アクセスを復元      |

## 🚀 インストール

注意: E2EEは一度有効化すると無効化できません。E2EEを使用せずに本プラグインの使用を継続したい際は、 [#復旧手順](#️復旧手順) を実行してください。

### Vault-Syncの設定画面から導入（推奨・スマートフォン対応）

1. Vault-Syncの設定画面「アドオン」の **アドオンを導入...** をタップ（またはコマンドパレットから `アドオンを導入する` を実行）
2. **ダウンロードページへ移動** をタップし、最新リリースの `vault-sync-e2ee-engine.zip` をダウンロード
    - zipにはエンジンと[追加利用条件](TERMS_ja.md)が同梱されています。最新版以外のバージョンは、Vault-Syncが拒否するため使用不可能です。
3. **ファイルを選択** でダウンロードしたzipを選択。Vault-Syncが検証し、追加利用条件を表示します
4. 追加利用条件を確認して同意し、**導入する** をタップ。再起動不要で有効化されます
5. コマンドパレットから `E2EE: Vaultの暗号化を開始する` を実行し、セットアップウィザードを完了してください

他デバイスで暗号化済みのVaultでは、起動時に導入ダイアログを自動表示し、導入後は直接パスワード入力に移行します。

### 手動コピーで導入（上級者向け）

1. [リリースページ](https://github.com/c-ardinal/obsidian-vault-sync-e2ee-engine/releases) から最新版の `e2ee-engine.js` をダウンロード
2. Vault-Sync のプラグインディレクトリに配置:
    ```
    <Your Vault>/.obsidian/plugins/obsidian-vault-sync/e2ee-engine.js
    ```
3. Obsidian を再起動し、コマンドパレットで暗号化開始コマンドを実行

手動で導入した際も、[追加利用条件](TERMS_ja.md)に同意したものとみなされます。

### ソースからビルド

1. 依存関係をインストール:

    ```bash
    npm install
    ```

2. エンジンをビルド:

    ```bash
    npm run build
    ```

3. `dist/e2ee-engine.js` をプラグインディレクトリにコピー:
    ```
    <Your Vault>/.obsidian/plugins/obsidian-vault-sync/e2ee-engine.js
    ```

`npm run build` は `dist/vault-sync-e2ee-engine.zip`（Vault-Syncがインポートするアドオンパッケージ: マニフェスト `addon.json`・エンジン・利用条件）も出力し、Vault-Syncが固定している各ファイルのSHA-256ハッシュを表示します。エンジン・バージョン・`TERMS` ファイルのいずれかを変更した際は、新規ハッシュを反映したVault-Syncのリリースが必要です。

## 🔒 セキュリティアーキテクチャ

### Vault Lock

`vault-lock.vault` ファイルは暗号化された Vault と一緒に保存され、以下の情報を格納します:

- 暗号化されたマスターキーマテリアル
- PBKDF2 のソルトとイテレーション数
- パスワードヒント（設定時のみ）

このファイルは Vault のロック解除に必要です。データの復号には、このファイルとパスワードの両方が必須です。  
このファイルはローカルには保管されず、クラウドストレージ上の以下の場所に格納されます。

```
  <Your Vault>/.obsidian/plugins/obsidian-vault-sync/data/remote/vault-lock.vault
```

## 🔧 技術仕様

| 項目         | 値                                                          |
| ------------ | ----------------------------------------------------------- |
| フォーマット | CommonJS (CJS)                                              |
| 暗号化方式   | AES-256-GCM（Web Crypto API）                               |
| 鍵導出       | PBKDF2-SHA256、600,000 イテレーション                       |
| IV サイズ    | 12 バイト（操作単位でランダム生成）                         |
| ローダー     | Vault-Sync がセキュアな `new Function` 評価器で動的にロード |

## ⚠️ 重要な注意事項

- **パスワードを厳重に管理してください**:
    - パスワードとリカバリーコードの両方を紛失した際は、暗号化されたデータの復号は不可能です。「リカバリーコードを表示する」コマンドでバックアップ用リカバリーコードをエクスポートし、安全な場所に保管してください。
    - 開発者であっても復元は不可能です。
- **vault-lock.vault をバックアップしてください**:
    - クラウドストレージにのみ存在します。このファイルは復号に不可欠です。紛失するとデータの復元は不可能です。
    - 開発者であっても復元は不可能です。
- **マルチデバイス**:
    - Vault を共有する全デバイスで同一のパスワードを使用する必要があります。特定のデバイスで E2EE を有効化すると、他デバイスでは次回同期時にパスワード入力を要求します。

## ❗️トラブルシューティング

### パスワード/リカバリーコード/vault-lock.vaultの紛失時

クラウドストレージ上のデータは**如何なる手段でも復号できません**。そのため、同期や履歴参照などの機能も利用不可能です。  
E2EEを使用せずに本プラグインの使用を継続したい際は、 [#復旧手順](#️復旧手順) を実行してください。

### E2EEの無効化

一度有効化したE2EEの無効化は不可能です。  
E2EEを使用せずに本プラグインの使用を継続したい際は、 [#復旧手順](#️復旧手順) を実行してください。

### 復旧手順

注意: 以下の手順を実行すると、プラグインの設定やファイルの変更履歴など、**Vault-Syncプラグイン関連の全データが消失します**。

1. Obsidian外の操作:ブラウザやクラウドストレージのアプリから、クラウドストレージ上のVaultフォルダ(デフォルト設定では、ObsidianVaultSync配下)を削除する。
2. Obsidianの設定 > コミュニティプラグイン > インストールされたプラグイン からVault-Syncをアンインストールする。
3. Obsidianを再起動する
4. Obsidianを起動し、設定 > コミュニティプラグイン > 閲覧 からVault-Syncを再インストールする。
5. Vault-Syncの設定からログインし、Vaultをクラウドストレージへアップロードする。
